打开页面即自动连接，不用点任何按钮。Broker 地址默认按当前电脑的 IP 自动推导 （双击本地文件打开时用 127.0.0.1），换电脑、换网络都不用改。 前提：电脑上 EMQX 已启动（1883 / 8083 端口），板子已上电并连上同一个 Wi-Fi。
请双击 打开看板.bat 或直接双击 index.html 用浏览器打开—— 在 IDE 预览窗口里看时，预览会拦截 WebSocket，页面会一直显示“重连中”。
